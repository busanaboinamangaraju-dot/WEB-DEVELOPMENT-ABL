# Case Study 1: Online News Portal

## Problem Statement
Design and develop an Online News Portal using HTML and CSS. The webpage displays National, International, Sports, Technology and Business news categories with headlines, images, descriptions and author details.

## Objectives
1. Create an attractive news webpage.
2. Display different news categories.
3. Use images to present news articles.
4. Apply CSS properties for styling.
5. Create hyperlinks for navigation.
6. Practice HTML elements and CSS fundamentals.

## Software Requirements
- Operating System: Windows
- Editor: Visual Studio Code or Notepad
- Technologies: HTML5 and CSS3
- Browser: Google Chrome

## Algorithm
1. Start.
2. Create the HTML document.
3. Add the website title and navigation links.
4. Create news categories.
5. Add featured news with an image and headline.
6. Add National, International, Sports, Technology and Business sections.
7. Add images, descriptions and author details.
8. Apply CSS colours, fonts, borders, padding and margins.
9. Add internal hyperlinks.
10. Save the files and open index.html in a browser.
11. Stop.

## Syllabus Concepts Used
HTML structure and elements, container elements, CSS syntax, class attribute, text alignment, text colour, background colour, font family, font size, text decoration, width, height, border properties, padding, margin, image element, ordered and unordered lists, anchor element, horizontal rule and HTML5.

## Test Cases
| Test | Expected Result |
|---|---|
| Open index.html | News webpage loads |
| Click National | National section is reached |
| Click Sports | Sports section is reached |
| Click Technology | Technology section is reached |
| Check images | News images are displayed when internet is available |
| Check styling | CSS colours and spacing are applied |
| Click Back to Top | Page returns to the top |

## Result and Conclusion
The Online News Portal was designed using HTML and CSS. It displays news categories, featured headlines, images, author information and navigation links.

## Note
The headlines and article descriptions are sample demonstration content, not verified current news. Images are loaded from external image links and require an internet connection.
