# Case Study 2: College Information and Admissions Website

## Problem Statement
Design a college information webpage that presents institutional information, departments, courses, faculty, admissions information, campus facilities, events and contact details.

## Objectives
1. Present college information in an organized webpage.
2. Display departments, courses and faculty details.
3. Provide admission information.
4. Present campus facilities using images.
5. Use hyperlinks for navigation within the webpage.

## Software Requirements
- Operating System: Windows
- Editor: Visual Studio Code or Notepad
- Technologies: HTML5 and CSS3
- Browser: Google Chrome

## Algorithm
1. Start.
2. Create the HTML document.
3. Add the college heading and navigation links.
4. Create the college introduction banner.
5. Add departments, faculty and admission information.
6. Add campus facilities and images.
7. Add events and contact information.
8. Apply CSS colours, fonts, borders, margins and padding.
9. Save the files and open index.html in a browser.
10. Stop.

## Syllabus Concepts Used
HTML structure and elements, container elements, CSS syntax, class attribute, text alignment, text colour, background colour, font family, font size, text decoration, width, height, background image, background size, border, padding, margin, HTML lists, image element, anchor element, viewport and HTML5.

## Test Cases
| Test | Expected Result |
|---|---|
| Open index.html | College webpage loads |
| Click About | About section is reached |
| Click Departments | Departments section is reached |
| Click Admissions | Admission section is reached |
| Click Facilities | Facility information is reached |
| Check images | Facility images are displayed |
| Click Back to Top | Page returns to top |

## Result and Conclusion
The College Information and Admissions webpage was designed using HTML and CSS. It presents institutional information, departments, faculty, admissions, facilities, events and contact details. Internal hyperlinks help users navigate the webpage.
